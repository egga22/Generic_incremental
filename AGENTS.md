# Repository instructions

Alpha (α) is an experimental feature. Leave its mechanics, upgrades, and progression alone, including known bugs, unless a fix is necessary to address a critical issue.

## Publishing changes

Push completed changes to `main` immediately, including GitHub issues, feature requests, and bug fixes from Gibson. If a pull request is needed, merge it yourself as soon as it is ready. For a brand-new feature proposed in chat, double-check the intended behavior before publishing if the scope is unclear. Apply actionable GitHub issues immediately without waiting for the user to merge.
